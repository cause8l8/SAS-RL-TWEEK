# Application artwork

Place the final Windows multi-resolution icon at `assets/sas_booster.ico`.
It should contain at least 16, 24, 32, 48, 64, 128, and 256 pixel layers, with
the 256 pixel layer stored as PNG inside the ICO. Keep a source-quality square
PNG as `assets/sas_booster.png` when one is available; the current Windows
release process only requires the ICO.
